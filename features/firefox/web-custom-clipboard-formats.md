# Firefox 웹 사용자 지정 클립보드 형식

동일 출처 웹페이지 사이에서 앱이 정한 데이터 형식을 복사·붙여넣도록 하는 Async Clipboard API 지원이다.

- Feature ID: firefox-web-custom-clipboard-formats
- 현재 근거: [161 Beta 공식 노트](https://www.firefox.com/en-US/firefox/161.0beta/releasenotes/#note-792535)의 Web Platform 항목.
- 최신 사건: [Beta 문서 관찰](../../data/events/firefox-web-custom-clipboard-formats-beta-161-observed-20261113.json).
- 관찰일: 2026-11-13 KST. Beta 첫 제공일 2026-11-09와 개별 기능 도입일을 구분한다.
- 한국 제공·한국어 지원: 미확인.
- 직접 시험: 미실행.
- 비교 과제: 동일 출처 합성 웹앱에서 형식·값 보존과 권한·출처 경계를 확인한다.
