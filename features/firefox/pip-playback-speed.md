# PiP 창 재생 속도 조절의 Stable 확대

## 2026-11-10 Stable 확대

기존 160 Beta에서 설명한 기능이 11/10 Release 노트에 수록됐다. 기능 전체 최초 도입이 아니라 Stable 확대 사건이다.

0.25배~2배. 중간 크기 이상 PiP 창에서만 메뉴 표시. PiP 자체 최초 도입 아님.

한국 제공·한국어 지원은 미확인. 직접 시험은 미실행입니다.

[변경 사건](../../data/events/firefox-pip-playback-speed-stable-160-20261110.json)

- [The Picture-in-Picture player now has a playback speed setting, with options ranging from 0.25x to 2.0x speed. The setting appears only when the player window is medium-sized or larger.](https://www.firefox.com/en-US/firefox/160.0/releasenotes/#note-792502)
- [기존 Beta의 선행 기능 설명과 대조](https://www.firefox.com/en-US/firefox/160.0beta/releasenotes/)

사용자 영향: 강의·영상의 속도를 바꾸기 위해 원래 탭으로 돌아가는 단계를 줄인다. 작은 창에서는 메뉴가 보이지 않아 크기에 따른 발견 가능성이 달라진다.

우선순위: 영상 시청 흐름의 제한된 개선이며 재생 상태·자막 일관성을 비교할 수 있어 P2로 둔다.

[앞선 160 Beta 분석](../../reports/2026-10-29.md)을 보존하며 이번 Stable 확대와 구분합니다.
