# Canva Docs 한국어 IME 중단 수정의 Beta 수록

## 161 Beta 기능 안내

한국어 조합 입력이 첫 글자 뒤 멈추던 특정 편집기 호환 문제를 수정한다고 안내한다. 모든 IME·사이트 개선은 아니다.

Firefox 161 Beta 공식 안내입니다. 11월9일은 Beta 최초 제공일이며 개별 항목의 발표·활성화일은 미확인입니다. Stable 제공이나 모든 기기 활성화를 뜻하지 않습니다. 한국 제공은 미확인이고 직접 시험은 미실행입니다.
