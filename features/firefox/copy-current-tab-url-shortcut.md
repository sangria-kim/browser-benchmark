# 현재 탭 URL 복사 단축키의 Beta 도입

## 161 Beta 기능 안내

반복 공유 작업의 주소창 선택 단계를 줄일 수 있다. 단축키를 직접 지정해야 한다.

Firefox 161 Beta 공식 안내입니다. 11월9일은 Beta 최초 제공일이며 개별 항목의 발표·활성화일은 미확인입니다. Stable 제공이나 모든 기기 활성화를 뜻하지 않습니다. 한국 제공은 미확인이고 직접 시험은 미실행입니다.

[공식 노트](https://www.firefox.com/en-US/firefox/161.0beta/releasenotes/#note-792450) · [사건](../../data/events/firefox-copy-current-tab-url-shortcut-beta-161-20261109.json)


## 2026-11-14 키보드 배열·플랫폼 조건 보충

[공식 단축키 사용자화 도움말](https://support.mozilla.org/en-US/kb/customize-keyboard-shortcuts-firefox)을 확인했다. 사용자화는 Windows·macOS·Linux 대상이며 Android·iOS는 지원하지 않는다. 영문 US QWERTY에 가장 적합하고 다른 키보드 배열의 지원은 제한적이라고 안내한다. 한국어 키보드에서 복사 키를 지정할 때 입력기 전환·운영체제 예약 키와의 충돌을 별도로 확인해야 한다. 이는 시험 질문이며 직접 시험 결과는 아니다.

도움말의 버전 147은 단축키 사용자화 기능의 기준이며, 현재 탭 URL 복사 동작의 출시 버전이 아니다. 해당 동작은 기존 161 Beta 사건을 유지한다. 한국 제공·한국어 UI 지원·한국 적용일은 미확인이며, 이번 조건 확인일을 발표일이나 배포일로 사용하지 않는다. 새 출시 사건이 아닌 기존 기능 제약의 보충이다.
