# Mini Window의 Firefox 160 Stable 수록

## 2026-11-10 Stable 확대

기존 160 Beta에서 설명한 기능이 11/10 Release 노트에 수록됐다. 기능 전체 최초 도입이 아니라 Stable 확대 사건이다.

탭 또는 페이지 일부를 항상 위 창으로 유지하는 초기 버전. Stable 브라우저의 초기 기능이며 모든 설치본 동일 노출을 단정하지 않음.

한국 제공·한국어 지원은 미확인. 직접 시험은 미실행입니다.

[변경 사건](../../data/events/firefox-mini-window-stable-160-20261110.json)

- [Mini Window moves a tab or a selected part of a page into an always-on-top window while browsing. We’d appreciate feedback on Mozilla Connect as we develop and improve this early version of the feature.](https://www.firefox.com/en-US/firefox/160.0/releasenotes/#note-792503)
- [기존 Beta의 선행 기능 설명과 대조](https://www.firefox.com/en-US/firefox/160.0beta/releasenotes/)

사용자 영향: 지침·레시피 등 페이지 일부를 항상 위 창으로 보면서 다른 탭에서 작업할 수 있다. 일반 영상 PiP와 달리 페이지 콘텐츠를 유지하며, 창 가림·포커스와 원본 복귀가 사용성의 핵심이다.

우선순위: 참고 내용을 유지하는 제한된 멀티태스킹 과제에서 탭 전환 부담을 비교할 수 있어 P2로 둔다.
