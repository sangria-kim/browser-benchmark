# Vivaldi 8.3에서 영상 종료 시 브라우저 전체화면 유지 수정

Feature ID: `vivaldi-browser-fullscreen-retention`

- 현재 판단: selected / P2 / 준비 상태: conditional.
- 버전·채널: 8.3 / stable.
- 발표 이름: Desktop minor update 2. 정확한 패치 빌드는 미공개.
- 적용 플랫폼: unknown.
- 발표일: 2026-11-10. 적용 완료일은 미확인.

## 변화와 사용자 영향

VB-132228은 HTML5 영상 전체화면을 종료할 때 브라우저 창 전체화면도 함께 종료되는 문제다. 이 수정이 11월 9일 8.4 snapshot에 이어 11월 10일 8.3 Stable 두 번째 minor 노트에 포함됐다. 이 본문은 전체 패치 버전을 명시하지 않는다.

영상과 페이지를 오갈 때 기존 창 모드를 유지하는 구체적인 작업 복구 차이가 있다.

## 삼성 브라우저 비교 질문

삼성 브라우저와 비교할 때, 영상 전체화면만 끝냈을 때 원래 브라우저 창의 전체화면 상태와 작업 맥락을 유지하는가?

## 비교 조건과 과제

- 비교 대상: Vivaldi 8.3 두 번째 minor 이후의 보안 업데이트된 빌드와 동일 OS의 삼성 브라우저 공개 빌드. 수정의 영향 OS가 본문에 없어 공통 지원 OS와 실제 설치 버전을 먼저 확인한다.
- 동일 조건: 동일 OS, 디스플레이, 배율 및 로컬 HTML5 영상 테스트 페이지를 사용한다. 브라우저 창 전체화면과 영상 전체화면을 구분한다. 계정이나 유료 구독 없이 가능한 영상으로 시험한다.
- 브라우저 창을 전체화면으로 전환한다.
- HTML5 영상을 전체화면으로 재생한다.
- 영상 종료 버튼과 Esc를 각각 시험하고 원래 창 상태를 확인한다.
- 지표: 창 모드 유지율, 필요한 복귀 조작 수, 초점 및 탭 연속성
- 결과 기록: 각 반복을 성공, 실패 또는 미지원으로 구분하며 실패와 미지원은 이유를 남긴다.
- 완료 기준: 영상 종료 버튼과 Esc를 각각 3회 시험한다. 브라우저 창 모드, 초점 및 원래 탭 유지 여부를 기록하고, 예상과 다른 동작은 재현 조건과 함께 남긴다.
- 실기 검증: 미실행.

## 지원 조건과 불확실성

Desktop 8.3 두 번째 minor 업데이트다. 해당 수정의 영향 OS, 플레이어별 상세 조건 및 정확한 패치 빌드는 본문에 명시되지 않았다. 개별 설치본은 확인하지 않았다.

한국 제공, 한국어 지원 및 한국 적용일은 미확인이다.
