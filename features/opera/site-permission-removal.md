# Opera 140에서 허용 사이트 권한 삭제 복구

Feature ID: `opera-site-permission-removal`

- 현재 판단: selected / P1 / 준비 상태: conditional.
- 버전·채널: 140.0.6074.17 / stable.
- 적용 플랫폼: Windows, macOS, Linux.
- 발표일: 2026-11-10. 적용 완료일은 미확인.

## 변화와 사용자 영향

Stable 본문이 허용 사이트의 권한 제거 복구를 명시하며, changelog의 RNA-5189가 대응한다. 140 Developer의 동일 수정이 Stable에 포함된 것으로, 새 권한 API 출시는 아니다.

사이트에 준 권한을 회수하는 개인정보 통제의 실패를 복구하므로 일반 시각적 수정과 구분한다.

## 삼성 브라우저 비교 질문

삼성 브라우저와 비교할 때, 허용 사이트 권한을 설정에서 지운 뒤 실제 사이트 접근과 다음 권한 요청이 일치하는가?

## 비교 조건과 과제

- 비교 대상: Opera 140.0.6074.17 이후의 보안 업데이트된 Stable과 동일 OS의 삼성 브라우저 공개 빌드. 해당 OS 지원과 권한 종류는 사전에 확인한다.
- 동일 조건: 동일 OS, 테스트 사이트, 권한 종류, 관리 정책 및 새 프로필을 사용한다. 계정 동기화는 끄거나 양쪽에서 같은 조건으로 맞춘다. 카메라나 위치 등 실제 개인정보를 전송하지 않는 시험 과제를 고른다.
- 안전한 시험 사이트에 권한을 허용한다.
- 설정에서 허용 사이트의 권한 항목을 삭제한다.
- 새로고침 및 재시작 후 권한 상태와 재요청을 확인한다.
- 지표: 삭제 성공률, 설정과 실제 권한의 일치, 권한 재요청 수
- 결과 기록: 각 반복을 성공, 실패 또는 미지원으로 구분하며 실패와 미지원은 이유를 남긴다.
- 완료 기준: 허용, 삭제, 새로고침 및 재시작 과정을 3회 반복한다. 삭제된 권한과 실제 사이트 동작이 일치하고 재요청 여부를 기록하면 완료한다. 실패는 단계와 조건을 함께 남긴다.
- 실기 검증: 미실행.

## 지원 조건과 불확실성

Desktop Stable 140. 공식 설치 링크는 Windows, macOS, Linux를 제공한다. 특정 권한 종류, 회귀 시작 버전, 국가 및 계정 조건은 미공개다. 모든 OS의 동일 동작을 직접 시험한 것은 아니다.

한국 제공, 한국어 지원 및 한국 적용일은 미확인이다.
