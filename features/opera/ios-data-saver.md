# Opera One iOS · Data Saver

기본 꺼짐. 메인 메뉴 또는 Settings에서 켜면 이미지와 텍스트가 Opera 서버에서 압축되어 iPhone으로 전달된다. 최대 80% 절감은 공급사 주장으로, 직접 측정한 결과가 아니다.

## 공식 이력과 날짜
- [App Store 공식 버전 이력](https://apps.apple.com/us/app/opera-browser-with-vpn/id1411869974): 6.8.0 Oct28, 6.8.1 Oct29, 6.8.2 Nov3에 Data Saver·설정이 수록돼 있다. 표시된 날짜를 개별 사용자 최초 활성화일로 바꾸지 않는다.
- [2026-11-12 공식 소개](https://blogs.opera.com/mobile/2026/11/data-saver-arrives-on-opera-one-for-ios-as-our-iphone-community-continues-to-grow/): 최신 버전에서 제공한다고 설명하지만 정확한 빌드는 명시하지 않는다. 앞선 버전 이력이 있으므로 이날을 최초 출시로 취급하지 않는다.
- Opera Mini/Android에서 먼저 제공되던 기술의 계보와 Opera One iOS 제품 지원은 구분한다.

## 제약과 비교 질문
한국 제공·한국어 UI·HTTPS 예외·압축 서버 데이터 보존·동영상 압축 범위는 미확인이다. 직접 실행하지 않았다. 삼성 브라우저에서 유사 기능을 검토한다면 데이터 절감과 서버 전송 안내, 이미지 품질·페이지 정상 표시의 균형을 어떻게 설명할 것인가?
