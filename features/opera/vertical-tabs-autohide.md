# Opera 141 Developer에서 세로 탭 자동 숨김 기본 켜짐

Feature ID: `opera-vertical-tabs-autohide`

- 현재 판단: selected / P2 / 준비 상태: conditional.
- 버전·채널: 141.0.6079.0 / developer.
- 적용 플랫폼: Windows, macOS, Linux.
- 발표일: 2026-11-09. 적용 완료일은 미확인.

## 변화와 사용자 영향

Developer 블로그가 기본 켜짐을 명시하고 changelog의 RNA-5563이 대응한다. 140의 타이밍 및 겹침 수정과 구분하며, Stable의 기본값 변경은 주장하지 않는다.

세로 탭으로 작업을 전환할 때 콘텐츠 공간, 발견성 및 포인터 이동이 달라지는 기본 동작이다.

## 삼성 브라우저 비교 질문

삼성 브라우저와 비교할 때, 세로 탭 자동 숨김이 콘텐츠 공간과 탭 재진입 및 드래그 오류에 어떤 영향을 주는가?

## 비교 조건과 과제

- 비교 대상: Opera 141.0.6079.0 Developer, Opera Stable의 현재 동작, 동일 OS의 삼성 브라우저 공개 빌드. 삼성 브라우저의 세로 탭 및 자동 숨김 지원은 확인 대상이다.
- 동일 조건: 동일 OS, 화면 배율, 창 크기, 탭 20개, 탭 제목 길이와 입력 장치를 사용한다. 새 프로필과 기존 프로필을 분리하고, Developer의 기본값을 Stable에 적용하지 않는다.
- 같은 창 폭과 탭 수에서 세로 탭을 선택한다.
- 기본 설정 상태 및 숨김과 노출 조건을 기록한다.
- 탭 전환, URL 드롭, 사이드패널 동시 사용 과제를 반복한다.
- 지표: 탭 진입 시간, 오작동 및 드롭 실패 수, 콘텐츠 가로 공간
- 결과 기록: 각 반복을 성공, 실패 또는 미지원으로 구분하며 실패와 미지원은 이유를 남긴다.
- 완료 기준: 각 설정에서 탭 전환과 URL 드롭을 3회 반복해 완료 시간, 오작동, 콘텐츠 공간을 기록한다. 비교 대상에 같은 기능이 없으면 같은 사용자 과제의 대체 경로를 기록하고 직접 기능 비교가 불가함을 표시한다.
- 실기 검증: 미실행.
