# Deprecate support for older versions of Windows 10

- 기능 ID: `chrome-6404936660287488`
- 확인일: 2026-11-06 KST
- 상태: pending_verification. 설치본과 실제 동작 검증은 미실행입니다.

Windows 10 버전 1809/build 17763 미만에서 Chrome 160이 최종 지원 버전이라는 공식 계획을 명시되어 있습니다. 기존 Chrome은 계속 실행되지만 이후 업데이트를 받지 않는다는 안내입니다.

현재 공식 지원 종료 계획이며 최초 대외 발표 시점의 근거는 미확인입니다. 11/4 수정일을 발표일 또는 지원 종료일로 사용하지 않습니다.

## 관찰 이력

- [2026-11-06 관찰 사건](../../data/events/chrome-windows10-pre1809-support-plan-160-20261106.json): first_observed_support_end_plan

## 검증 조건과 재개

공식 문서의 본문 변경 근거이며 최초 출시의 증거는 아님. 문서 수정일을 출시일로 쓰지 않음.

한국 제공·한국어 지원은 미확인입니다. 문서 수정일과 최초 발견일은 출시일이 아닙니다. 공식 단계와 기기·계정·정책 조건을 확인한 뒤 비교합니다.
