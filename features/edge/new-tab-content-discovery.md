# Desktop 새 탭의 콘텐츠 탐색 개편과 기존 Curated by Copilot 경험 확대를 5개국에 발표

- Feature ID: `edge-new-tab-content-discovery`
- 채널/버전: public_rollout_announced / 미명시
- 범위: Desktop Edge. 기사에 세부 OS 버전은 열거하지 않는다. Windows Discover는 함께 발표된 별도 화면이며 모바일은 향후 범위다.
- 선별: selected / P2 / pm-selection-v2

## 이력

### 2026-11-05 공식 발표, 2026-11-06 KST 확인

- [사건 데이터](../../data/events/edge-new-tab-content-redesign-20261105.json) · [날짜별 보고](../../reports/2026-11-06.md)
- 이전: 새 탭 콘텐츠 추천과 Curated by Copilot은 기존 기능이다. 정확한 과거 국가별 범위는 이번 자료에서 확정하지 않았다.
- 현재: 재설계한 추천·탐색 화면, 더 두드러진 동영상 배치, 기존 AI 종합 보기 확대를 11/5 Desktop의 5개국에 발표했다.
- 신규성: 당일 공식 출시 선언과 화면/추천 변화. AI feed 최초 발명이나 모든 국가에서의 최초 제공으로 세지 않는다.
- 발표일: 2026-11-05. 실제 사용자별 적용일: 미확인.

## PM 검토

- 사용자 영향 및 선정 이유: 새 탭에서 콘텐츠를 고르고 출처를 탐색하는 경로가 바뀌며, 국가 제한을 분리한 비교 과제를 정의할 수 있다.
- 비교 질문: 동일 관심 주제로 새 탭에서 신뢰할 원문 2개를 찾을 때 추천·AI 종합·출처 링크가 탐색 단계와 선택에 어떤 차이를 만드는가?
- 우선순위: P2. 반복 접점인 새 탭 변화이나 초기 지역이 제한되어 탐색적 비교가 적합하다.
- 벤치마크 준비: conditional. 지원 국가의 동일 Windows 환경에서 관심 주제 하나를 정하고 새 탭→추천/종합 보기→원문 2개로 이동한다. 주제·게시자 팔로우와 화면 설정 경로도 기록한다.
- 측정: 조작·입력 횟수, 완료 시간, 목표 일치·오류 여부. 원문 탐색은 출처 식별·원문 이동 성공도 기록한다.
- 완료 기준: 노출 여부와 시험 환경을 먼저 기록하고 과제를 양쪽에서 같은 조건으로 반복할 수 있어야 한다. 미노출은 그 환경의 결과로만 남긴다.
- 실기: 미실행. 외부 공식 QA를 자체 검증 결과로 간주하지 않는다.

## 한국 적용과 조건

- 한국 제공·한국어: 미확인. 초기 발표 5개국에 한국은 포함되지 않으며 한국 확대일·한국어 제공은 미명시. 모바일은 향후 확대 계획.
- 한국 적용일: 미확인. 계정·구독·연령 등 명시되지 않은 조건을 추정하지 않는다.
- 재검토: 지원국 Windows 환경에서 노출 확인, 한국 또는 모바일 확대의 공식 발표, 계정·언어 조건 변경.
