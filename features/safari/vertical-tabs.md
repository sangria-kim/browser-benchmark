# Safari · 세로 탭

- Feature ID: `safari-vertical-tabs`
- 2026-11-03: Safari 27.3 beta 공식 설명. 정식 출시는 확인되지 않았다.
- Safari 27.3 beta 릴리스 노트 Browser 항목은 세로 레이아웃으로 탭을 탐색·관리하는 기능을 명시한다.
- 기능별 OS 노출 조건은 이 항목에 구분되지 않는다. 전체 릴리스의 지원 OS를 모든 기기의 세로 탭 제공 근거로 사용하지 않는다.
- 한국 제공·한국어 지원·실기: 미확인 / 미확인 / 미실행.
- 비교 질문: 세로 탭과 가로 탭에서 같은 수의 탭을 찾고 전환할 때 제목 식별과 콘텐츠 공간은 어떻게 달라지는가?
