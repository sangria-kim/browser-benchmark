# Brave Search 결과 링크 URL cloaking 도입 예고

향후 며칠 내 검색 결과 링크를 암호화된 중계 주소로 바꿀 예정. 복사한 주소는 원래 목적지가 아니며 만료될 수 있다. JavaScript가 켜진 경우 POPRF로 클릭 목적지를 숨긴다고 설명하지만 JS 비활성화 시 일반 리디렉션으로 서버가 목적지를 볼 수 있다.
