- Feature ID: `brave-split-view-edge-drag`
- 채널/버전: stable / 1.99.55
- 범위: 공식 latest의 Desktop 절. GitHub의 Android/iOS 설치 artifact 안내 및 QA label을 Stable 모바일 출시 근거로 사용하지 않는다.
- 선별: selected / P2 / pm-selection-v2

- 현재: 1.99.55 정식 노트에 설정 재활성화가 명시됐다. 공개 Beta QA는 기본 켜짐과 탭 드래그·가로/세로 탭 동작을 확인했으며, 정식 설치본 기본값은 직접 확인하지 않았다.

- 발표일: 2026-11-05. 실제 사용자별 적용일: 미확인.

## PM 검토

- 사용자 영향 및 선정 이유: 탭을 창 가장자리로 끌어 두 페이지를 나란히 보는 직접 조작 경로가 정식 채널에 돌아온다.
- 비교 질문: 동일한 두 문서 비교 과제에서 가장자리 드래그와 메뉴 기반 분할 방식은 조작 수·오작동·소요 시간에 어떤 차이가 있는가?
- 우선순위: P2. 두 문서를 나란히 보는 반복 과제의 직접 조작 경로가 바뀌어 P2 비교 과제로 선정한다. 기존 기능 복귀이며 대규모 새 범주 도입은 아니다.
- 벤치마크 준비: conditional. Windows 정식 1.99.55에서 설정 노출·초기값 기록→좌우 가장자리 각각 드래그→끄기/켜기→가로·세로 탭에서 반복. 탭 그룹 분리 후 충돌 유무를 관찰하되 이전 취약 버전을 설치하지 않는다.
- 측정: 조작·입력 횟수, 완료 시간, 목표 일치·오류 여부. 원문 탐색은 출처 식별·원문 이동 성공도 기록한다.
- 완료 기준: 노출 여부와 시험 환경을 먼저 기록하고 과제를 양쪽에서 같은 조건으로 반복할 수 있어야 한다. 미노출은 그 환경의 결과로만 남긴다.
- 실기: 미실행. 외부 공식 QA를 자체 검증 결과로 간주하지 않는다.
