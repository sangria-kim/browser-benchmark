# macOS 최소 지원 버전 변경 예고

2026-11-10 공식 한영 공지는 macOS 12→13 변경 예정과 기존 설치본의 업데이트 중단을 안내한다. 시행일·브라우저 버전은 미공개다. 기존 설치본 즉시 실행 중단으로 해석하지 않는다.

## 2026-11-11 릴리스 노트 근거

5.41.429.5 한영 릴리스 노트는 macOS 13 이상을 요구하며 macOS 12의 마지막 지원 버전을 5.39로 명시한다. 별도 예고 공지는 미래형을 유지한다. 노트의 적용 날짜와 실제 설치본 적용을 구분한다. 이전 예고 판정은 위 이력으로 보존한다.

[추가 사건·조건](../../data/events/whale-macos13-5414295-support-evidence-20261111.json)

[공식 운영팀 공지](https://forum.whale.naver.com/topic/63268/)는 macOS 12 이하 환경에 잘못된 자동 업데이트가 전달됐다고 안내한다. 이전 버전 재설치와 해당 OS의 자동 업데이트 차단 조치를 설명한다. 공지 작성일은 11월 10일이나 이 정정의 삽입 시각은 미공개다. 사용자 댓글을 근거로 삼지 않았다.

새 지원 경계와 잘못된 업데이트 후 복구 과제를 selected/P1로 판정한다. 이는 전체 기기 적용 완료 판정이 아니다. 실제 효력일과 오류 빌드는 미확인으로 유지한다.
