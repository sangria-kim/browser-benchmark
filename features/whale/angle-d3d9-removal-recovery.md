# Whale 5.41의 D3D9 설정 전환과 영상 CPU 부담 복구 안내

Feature ID: `whale-angle-d3d9-removal-recovery`

- 버전·채널: 5.41 / unknown.
- 적용 플랫폼: Windows.
- 발표일: 2026-11-12T06:20:41Z. 적용 완료일은 미확인.

## 변화와 사용자 영향

운영팀은 과거 ANGLE을 D3D9로 강제 설정한 Windows 설치가 5.41 업데이트 후 D3D11 WARP로 전환된다고 설명한다. GPU 대신 CPU 렌더링을 사용해 부담이 커지며, Default 복귀와 재시작 후 GPU 상태 확인을 안내한다. 전일의 macOS 지원 종료 및 업데이트 복구 사건과는 다르다.

영상 재생 성능 회귀의 구체적인 발생 조건과 사용자 복구 경로가 공식 확인되어 비교할 수 있다.

## 삼성 브라우저 비교 질문

삼성 브라우저와 비교할 때, 구버전 그래픽 설정이 사라질 때 기본값 복구, 안내, 영상 재생 자원 사용은 어떻게 달라지는가?

## 비교 조건과 과제

- 비교 대상: Windows의 Whale 5.41과 동일 OS에서 사용 가능한 삼성 브라우저 공개 빌드. 삼성 브라우저의 지원 빌드와 그래픽 진단 방법은 시험 전에 확인한다.
- 동일 조건: 동일 PC, GPU 드라이버, 전원 모드, 디스플레이, 영상 파일, 코덱 및 해상도를 사용한다. Whale은 과거 D3D9 설정이 남은 프로필과 Default 복귀 프로필을 구분한다. 다른 브라우저에 동일 플래그가 있다고 가정하지 않는다.
- 기존 D3D9 설정 시험 프로필의 업데이트 전후 GPU 렌더러를 확인한다.
- 동일 영상, 해상도, 코덱에서 CPU/GPU 부담을 관찰한다.
- Default 복귀 및 재시작 후 렌더러와 자원 사용을 비교한다.
- 지표: 렌더러 상태, 평균 및 최대 CPU 사용률, 프레임 누락, 복구 단계와 소요 시간
- 결과 기록: 각 반복을 성공, 실패 또는 미지원으로 구분하며 실패와 미지원은 이유를 남긴다.
- 완료 기준: Default 복귀 후 렌더러가 WARP가 아닌지 기록하고, 동일 영상 과제를 3회 실행해 CPU 사용과 프레임 누락의 전후 차이를 남긴다. 삼성 브라우저는 동일 영상 과제의 관찰값만 비교한다.
- 실기 검증: 미실행.

## 지원 조건과 불확실성

Windows에서 과거 #use-angle=D3D9를 직접 설정한 사용자에게 해당한다. 새 설치, 모든 사용자 또는 다른 브라우저의 동일 현상으로 일반화하지 않는다. 정확한 5.41 하위 빌드와 최초 제거일은 미공개다. 공지는 5.41을 통칭하며 Stable과 Beta의 개별 적용 범위는 명시하지 않는다.
