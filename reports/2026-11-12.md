### 2. 사용자 영향

macOS 12 사용자는 기존 설치본을 계속 사용할 수 있어도 새로운 기능·보안 업데이트를 받지 못하는 경계에 놓인다. 잘못된 업데이트를 받은 사용자는 이전 버전으로 돌아가는 추가 과제가 생긴다. 기존 설치본이 일괄 실행 중단됐다고 해석하지 않는다. 재설치 시 프로필·북마크·비밀번호가 보존되는지는 공식 공지만으로 확인되지 않는다.

### 3. 제품 비교

비교 질문은 지원 종료 안내, 업데이트 차단, 오류 복구 경로의 명확성이다. 삼성 브라우저의 macOS 지원 여부나 동작 차이는 추정하지 않는다. 같은 OS에서 사용할 수 있는 공식 비교 제품을 먼저 확인하고, 동일 플랫폼 비교가 불가능하면 지원 종료 안내 UX만 별도 문서 비교한다.

### 4. 벤치마크 후보

- 과제: 지원 종료 OS에서 업데이트 상태를 이해하고 필요한 복구 경로를 찾는다.
- 환경: 격리된 macOS 12/13 테스트 장치, 개인정보 없는 프로필, 동일 네트워크·언어·계정 상태. 운영 장치의 다운그레이드나 보안 경고 우회는 하지 않는다.
- 버전: 공식 5.39 설치본과 5.41.429.5의 OS 요구사항·제공 경로를 먼저 확인한다. 오류 빌드가 미확인이므로 임의로 재현을 주장하지 않는다.
- 단계: 최소 OS 안내 확인 → 업데이트 확인 화면 관찰 → 지원 종료 설명과 이전 버전 안내 확인 → 안전한 시험 조건이 확보된 경우만 테스트 프로필 복구 절차 확인.
- 지표: 안내 도달 단계·시간, OS/버전 조건 명확성, 오류 메시지, 복구 절차 성공 여부, 테스트 프로필 보존 여부.
- 완료 기준: OS별 업데이트 허용·차단 결과와 안내 경로가 기록되고, 복구를 시험했다면 사용 데이터 보존 여부를 증거로 남긴다. 미실행 항목은 실패로 계산하지 않는다.

### 5. 출시 범위와 한국 조건

릴리스 노트는 Stable·Beta 5.41.429.5의 요구사항을 제시하지만, 별도 공지의 미래형과 차단 조치 중이라는 설명은 남아 있다. 실제 장치별 적용은 확인하지 않았다. 한국어 공식 문서가 있다는 사실과 한국 전체 배포를 구분한다. 한국 제공·한국어 기능 지원·한국 적용일은 미확인, 실기 검증은 미실행이다.
