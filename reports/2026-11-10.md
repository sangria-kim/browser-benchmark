### 변경과 사용자 영향
10/29 Mobile Beta에 있던 Entra ID 패스키 동기화가 11/9 Android·iOS Stable 157.0.4341.42 노트에 추가됐다. 기업용 패스키 동기화 전체의 최초 도입은 아니다.
Mobile Beta 10/29 선행, Desktop Stable 149(6/4) controlled rollout 선행 및 151(7/31) 반복 안내를 본문으로 대조했다. 새 사건은 11/9 Mobile Stable 확대이며 모든 소비자 계정 지원으로 일반화하지 않는다.

### PM 선별
P1 · 업무 계정 자격증명의 기기 간 동기화는 인증 경계와 기존 로그인 연속성에 영향을 준다. 모바일 Stable 확대에 맞춰 계정 분리·정책 제한·기존 자격증명 보존을 우선 검토한다.
삼성 브라우저의 업무 계정 패스키는 어떤 기기·계정·저장소 경계에서 이용 가능하며 로그아웃·관리 정책 변경 뒤 기존 로그인의 연속성은 어떻게 달라지는가? 공개 근거와 시험으로 확인한다.

### 벤치마크 후보
- 동일 조건: 같은 기기·OS·계정 유형·언어·지역·웹사이트 조건. Edge 기능 노출과 비교 브라우저 지원 여부를 먼저 확인한다.
1. 승인된 시험용 Entra 계정과 합성 로그인 사이트를 준비한다
2. 동일 계정의 Windows PC·Android에서 패스키 저장·동기화·로그인을 비교한다
3. 정책 허용·차단과 로그아웃 상태를 분리해 확인한다
4. 기존 패스키 사용과 신규 저장 제한의 차이를 확인한다
- 지표: 기기 간 로그인 성공률·조작 수, 동기화 지연, 계정 혼동·실패 안내, 기존 자격 증명 보존
- 완료 기준: 지원 조건을 기록하고 각 흐름을 3회 반복하여 성공·실패와 차이를 근거 화면으로 설명할 수 있을 때 완료
- 실행: 미실행 / 준비: conditional
