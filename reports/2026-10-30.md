**사용자 영향:** 이미 실행 중인 브라우저로 돌아가는 대기 시간이 줄어들 가능성이 있다. 공급사 제시 15%, 과중 멀티태스킹에서 최대 33%는 독립 실측 결과가 아니다. 콜드 스타트나 페이지 로딩 개선을 뜻하지 않는다. [Edge 공식 발표](https://blogs.windows.com/msedgedev/2026/10/29/edge-is-faster-on-windows-with-accelerated-app-launches/)

API는 잠금 해제 토큰이 필요한 제한적 접근 기능이며 모든 호출 경로와 OS를 지원하는 것은 아니다. [Microsoft API 문서](https://learn.microsoft.com/en-us/windows/apps/develop/launch/accelerated-launch)

삼성 브라우저의 채택, 기능의 최초 제공일, 한국에서의 실제 배포 및 한국어 환경 동작은 이번 확인 범위에서 확정하지 못했다.

### 선정 이유와 우선순위

- **선정 이유:** 공개 설명만 새로 게시된 경우로 처리하지 않고, Windows 업데이트에 포함된 배포 조건을 확인할 수 있는 실행 경로 변화로 채택했다. 10월 29일을 기능의 최초 등장일로 단정하지 않는다.
- **P2 판단:** 외부 링크에서 브라우저로 돌아가는 일상적 흐름과 연결되고 측정 과제로 구체화할 수 있다. 다만 지원 환경과 배포 상태에 의존하며 독립 검증이 없어, 즉시 성능 우위로 결론내릴 단계는 아니다.
- **준비 상태:** 조건부. 지원 빌드·KB 설치 여부와 실제 직접 전달 경로가 확인되어야 본 측정을 시작할 수 있다.

| 현재 확인 범위 | 기능 자체는 초기 프리뷰다. `Settings → Opera AI → Enable Web AI API`에서 사용자가 활성화해야 모델을 내려받는다. Prompt·Decision·Semantic Embeddings API를 제공하며, 소개된 예제 확장 6개는 기본 내장 기능이 아니다. [WebAI 소개](https://blogs.opera.com/news/2026/10/webai-local-ai-for-the-web-now-in-opera/), [실험 문서](https://next.opera.com/web-ai/) |

지원 대상으로 명시된 환경은 Intel·AMD 기반 Windows x64와 Apple Silicon Mac이다. Linux, Intel Mac, Windows ARM은 제외된다. 한국에서의 실제 이용 가능 여부와 한국어 지원·품질은 확인하지 못했다. [WebAI 소개](https://blogs.opera.com/news/2026/10/webai-local-ai-for-the-web-now-in-opera/)

**사용자 영향:** 활성화 후 웹 AI 작업을 기기에서 처리할 수 있다는 공급사 설명이다. 로컬 처리·개인정보 보호에 관한 설명을 독립 검증 결과로 취급하지 않으며, 네트워크 동작과 실제 작업 품질은 측정이 필요하다. [WebAI 소개](https://blogs.opera.com/news/2026/10/webai-local-ai-for-the-web-now-in-opera/)

### 선정 이유와 우선순위

- 이벤트 ID: `opera-web-ai-local-apis-stable-139-inclusion-20261027`.
- **선정 이유:** 기존 프리뷰 소개를 다시 신규로 세지 않고, Stable 139에 포함된 배포 접점을 평가한다. 재검토 구간에서 발견한 항목이며 이번 수집 구간에 처음 공개됐다는 의미는 아니다.

- **준비 상태:** 조건부. 지원 기기와 브라우저·모델 버전, 활성화 여부를 확인하고 공개·합성 데이터로 테스트를 구성한 뒤 진행한다.

| 네트워크 확인 | 준비·다운로드 단계와 추론 단계의 통신을 분리 관찰한다. 다운로드 후 오프라인에서도 같은 작업을 시도한다. 관찰된 요청이 없다는 사실만으로 모든 환경의 개인정보 보호를 증명했다고 결론내리지 않는다. |

**완료 조건:** 재현 가능한 입력 세트와 정답·채점 기준, 환경·모델 명세, 준비 비용과 최초·반복 추론의 분리 결과, 품질·안정성 지표, 네트워크 및 오프라인 관찰 기록을 남긴다. 실행 불가나 한국어 품질 부족도 결과로 기록한다.

## 나머지 검토 결과

- Chrome Enterprise·Chrome Releases·ChromeStatus, Firefox, Brave, Vivaldi와 Edge의 나머지 항목을 검토했다. 확인된 단순 패치·중복 발표·프리뷰 기준선은 이번 채택에서 제외했다.
- Opera GX 검색은 기존 본문 검색과 구분되는 새로운 변화가 확정되지 않아 보류했다. Opera·Vivaldi는 주간 최초 검토 범위에 포함했다.
- Chromium flags는 `2026-10-29T22:39:00Z` 기준 소스 확인이며 설치 상태를 검증하지 않았다. 과거 메타데이터 이력과 삭제된 소스의 확인은 불완전하다.
- 모든 브라우저·기간·소스에 대한 검증 완료나 변화 없음을 뜻하지 않는다. 세부 범위와 보류 사유는 [수집 상태](../docs/collection-status.md)를 참고한다.
