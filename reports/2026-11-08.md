# 2026-11-08 브라우저 기능 분석

- 분석 기준: `pm-selection-v2`. 공식 종료 예고 1건을 selected / P1로 다룹니다.
- Edge Performance detector의 버전 164 종료 **계획**입니다. 실제 종료 완료가 아닙니다.
- 공식 문헌 기반 분석이며 설치본·한국 단말·직접 벤치마크는 미실행입니다.

## Edge: Performance detector 종료 예고

### 사실과 날짜

- Event ID: `edge-performance-detector-retirement-plan-164-20261106`
- Feature ID: `edge-performance-detector`
- 문서가 실린 버전·채널: **158.0.4370.7 Beta**. 종료 목표: **164**, 정확한 적용일은 미공개.
- 공식 노트 날짜: **2026-11-06**. 관찰: **2026-11-08 KST**. 노트 날짜를 실제 종료일로 사용하지 않습니다.
- 플랫폼: 현재 관련 정책의 Windows·macOS 지원을 기준으로 PC 과제를 검토합니다. Android·iOS 종료로 확대하지 않습니다.
- 업무: pc. AI 관련: false. 사건 분류: planned_retirement.

[공식 Beta 노트](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-relnote-beta-channel#version-158043707-november-6-2026)의 `Announcements / Performance detector retirement`는 Performance detector를 종료하고 관련 `PerformanceDetectorEnabled` 정책을 사용 중단할 계획이라고 밝힙니다. 기능 종료와 정책 obsolete 처리는 Edge 164에서 예상된다고 기재되어 있습니다. 현재 158에서 이미 없어졌다고 해석하지 않습니다.

[관련 정책 본문](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/performancedetectorenabled)은 탭 성능 문제를 감지하고 해결 권고를 표시하는 기존 동작을 설명합니다. 따라서 이번 변화는 브라우저 자체의 성능 하락·개선이나 Sleeping Tabs 전체 종료가 아니라, **문제 탭을 찾아 조치하도록 돕는 기존 진단 기능의 종료 계획**입니다. 이 발표에는 대체 UI·동등 기능·이관 절차가 명시되지 않았습니다. 대체 기능이 없다고 단정하지 않습니다.

### 이전 근거와 구분

공식 Beta archive의 107.0.1418.8(2022-10-13)은 해당 정책의 도입입니다. 158.0.4370.7(2026-11-06)의 164 종료 계획과 다른 사건입니다. 예고의 최초 대외 공개 시점을 모든 과거 revision에서 확정한 것은 아닙니다. 실제 제거·배포 완료는 후속 공식 근거로 별도 판단해야 합니다.

### 사용자 영향과 PM 판단

- 사용자 과제: 느려진 브라우저에서 어떤 탭이 문제인지 찾고 적절한 조치로 돌아오기.
- 예상 영향: 기존 진단 권고에 의존하던 사용자는 안내 진입 경로나 문제 탭 식별 방식이 달라질 수 있습니다. 구체적인 대체 동작은 아직 미확인입니다.
- 선정 상태: **selected**. 종료가 아니라 종료 예고 자체의 신규성과 사용자 과제 영향을 평가했습니다.
- 우선순위: **P1**. 기존 기능 삭제 계획은 발견·조치 경로를 미리 비교할 가치가 있습니다. 버그 심각도나 성능 저하 등급이 아닙니다.
- 검증 준비 상태: **conditional**. 현재 기능의 실제 노출, 종료 적용 빌드 및 대체 경로를 먼저 확인해야 합니다.
- 삼성 브라우저 비교 질문: 같은 고부하 탭 과제에서 문제를 인지하고 원인을 찾아 해결하는 경로가 있는가? 그 경로의 발견성·조작 수·실패 복구는 어떻게 다른가? 동등 기능의 존재나 우열을 추정하지 않습니다.

### 벤치마크 후보

1. 같은 Windows PC, 같은 계정 유형·관리 정책·확장 기능·탭 구성·전원 상태와 재현 가능한 무해한 로컬 고부하 페이지 세트를 준비합니다. 비교할 삼성 브라우저가 동일 플랫폼에서 지원·설치되는지부터 확인합니다.
2. 현재 Edge에서 Performance detector의 실제 노출 및 정책 상태를 기록합니다. 문제 탭을 찾기, 권고 이해하기, 조치하기, 원래 작업으로 복귀하기의 경로와 결과를 관찰합니다. 정책을 바꾸는 실험은 별도 승인된 시험 환경에서만 합니다.
3. 향후 164에서 공식 종료 적용이 확인되면 같은 과제를 반복하고 대체 안내·기본 경로를 기록합니다. 단순히 버전 숫자가 164라는 이유만으로 종료됐다고 가정하지 않습니다.
4. 같은 플랫폼의 비교 브라우저에도 동일 과제를 적용합니다. CPU·메모리 값은 조건 확인 자료이며 기능 종료만으로 브라우저 성능 변화를 결론 내리지 않습니다.

- 지표: 문제 탭 식별 시간·정확도, 조치까지의 조작 수, 권고 이해도, 잘못된 탭 종료, 원래 작업 복귀 성공률, 대체 경로 발견 여부.
- 완료 기준: 현재 동작과 종료 적용 후 상태를 각각 확인하고 같은 탭 세트에서 세 번 이상 반복한 비교 기록을 확보합니다. 기능 미노출·종료 미적용·정책 차이는 결과와 구분해 기록합니다.
- 실행 여부: **미실행**. 현재 결과는 시험 설계이며 측정값이나 개선 효과가 아닙니다.

### 한국 적용과 미확인 조건

- 한국 제공: **미확인**. 한국어 지원: **미확인**. 한국 적용일: **미확인**.
- 국가·언어·계정별 종료 일정과 대체 기능의 조건은 이번 공식 예고에 명시되지 않았습니다.
- 현재 정책 지원 OS와 최종 종료 범위는 구분합니다. 한국어 번역 문서의 존재나 특정 설치본 미노출을 한국 전체 상태로 일반화하지 않습니다.
- 재검토 조건: Stable 노트의 종료 예고/실제 적용, 정책 지원 범위 변화, 대체 기능 공식 안내, 승인된 동일 환경 시험 결과.
