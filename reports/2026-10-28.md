## 1 Smart Window 페이지 변화 감시: 새 Release 단계, 기능은 beta·점진 배포

### 확인된 변화와 근거

[Firefox 159 공식 노트](https://www.firefox.com/en-US/firefox/159.0/releasenotes/)는 10월 27일 Release 제공과 Smart Window의 /watch 명령을 명시합니다. [같은 날 공식 발표](https://blog.mozilla.org/en/firefox/skip-the-busywork-with-smart-window/)는 특정 가격·재입고 등 조건을 정해 매일 또는 매주 확인하되 **브라우저가 열려 있을 때만 실행**한다고 설명합니다. 브라우저 Stable과 AI 기능 beta는 별개이며 실시간 상주 감시가 아닙니다.

[전용 도움말](https://support.mozilla.org/en-US/kb/create-tasks-smart-window)은 작업당 최대 5개 페이지, 최대 15개 활성 작업, Tasks 및 about:smartwindowtasks의 편집·일시중지·삭제를 설명합니다. 감시는 채팅에서 선택한 모델과 별개인 Qwen을 사용합니다. 알림은 일치 발견 시 작업 패널에 표시되고, 데스크톱 알림 활성 상태에서는 시스템 알림도 이용합니다.

### 사용자 영향과 제품 비교 질문

반복 새로고침을 조건 기반 확인에 맡길 수 있습니다. 반면 브라우저 종료·미실행 시간에는 감시가 이루어지지 않으므로 ‘24시간 자동 감시’라는 인상을 주지 않는 안내가 중요합니다. 제품 비교는 조건 입력의 명확성, 실행 상태·마지막 확인 시각·중지 상태의 이해 가능성, 불필요한 알림의 억제에 초점을 둡니다. 삼성 브라우저에 같은 기능이 있는지, 없는 경우 수동 재방문과 어떤 차이가 나는지는 확인 질문입니다.

### 구체적인 벤치마크 후보

- 우선순위 P1. 과제: 공개 합성 상품 페이지의 가격이 목표 이하가 됐을 때 확인하고, 무관한 문구 변경은 알림으로 오인하지 않기.
- 동일 Windows PC·OS·언어·네트워크·합성 URL 3개·가격 데이터·검사 주기를 통제합니다. Firefox 159의 실제 기능 노출 계정과 수동 재방문을 기본 비교군으로, Chrome·Edge·삼성은 기능 확인 후 비교군을 추가합니다. 미지원은 점수 0이 아니라 별도 표시합니다.
- 재현: 정확한 빌드·지역·언어·계정과 기능 노출 확인 → /watch에 목표 조건과 공개 페이지 등록 → 일일 검사 예약 → 가격 조건 일치·무관한 문구 변경·변화 없음의 세 경우를 각 3회 관찰 → 작업 일시중지·재개 → 브라우저 종료 조건과 열린 조건을 분리해 확인합니다.
- 지표: 등록 조작 수, 조건 이해 오류, 예정 검사 대비 실제 알림 지연, 참/거짓 양성, 중복 알림, 일시중지 후 잔여 알림, 재개 후 상태 설명.
- 완료 기준: 세 조건 각 3회와 종료/중지/재개 결과의 시각·증거를 확보합니다. 일일 검사 기능이므로 몇 분짜리 시험으로 감지 성공률을 발표하지 않습니다. 권한 변경·로그인·예약 작업 생성은 별도 승인된 시험 환경에서만 수행합니다. 이번 조사에서는 생성하지 않았습니다.

### 범위·불확실성

신규 감시 기능의 공식 범위는 **desktop, 영어, 미국·캐나다**입니다. [Smart Window 일반 도움말](https://support.mozilla.org/en-US/kb/smart-window)의 프랑스·fr 범위를 이 기능에 확대하지 않습니다. Mozilla 계정과 Smart Window 이용 조건이 필요하며 한국어·국내 노출은 미확인입니다. 릴리스 노트는 점진 배포를 명시합니다.

자동 중지는 문서 간 차이가 있습니다. 블로그는 60일 무일치 후 일시중지 및 90일 무변화 후 중단이라고 설명하지만, 전용 도움말은 모든 작업을 생성 90일 후 일시중지한다고 씁니다. **90일 기준과 재개 정책은 미확인**으로 남기고 UI·지원 답변으로 확인해야 합니다. 도움말의 ‘4주 전 생성’ 상대 표기는 최초 배포일이 아닙니다. 10월 27일은 이번 Release 단계·공식 발표 근거이지 기능 최초 공개일이라고 단정하지 않습니다.

## 2 AI ‘페이지 요약’: 본문 대신 주소 전달

### 확인된 변화와 근거

[159 Release 노트](https://www.firefox.com/en-US/firefox/159.0/releasenotes/)는 AI chatbot의 Summarize page가 페이지 본문 대신 주소를 공급자에게 보내도록 바뀌었다고 명시합니다. **선택한 텍스트 요약**이나 Smart Window 감시와는 다른 경로입니다. [AI chatbot 도움말](https://support.mozilla.org/en-US/kb/ai-chatbot)은 사이드바 또는 우클릭의 페이지 요약 진입을 설명하지만 FAQ의 본문 전달 설명은 아직 남아 있어 버전별 정합성 확인이 필요합니다.

### 사용자 영향과 제품 비교 질문

긴 페이지의 일부만 전달되는 문제를 줄이려는 변경입니다. 다만 URL만 전달한다고 개인정보 노출이 없거나 모든 페이지를 읽을 수 있다는 뜻은 아닙니다. 로그인·접근 제한·동적 내용·URL 쿼리 정보에 따른 정확도와 실패 안내를 확인해야 합니다. 삼성·Chrome·Edge의 요약도 ‘현재 렌더링 본문’, ‘공개 URL’, ‘선택 텍스트’ 중 무엇을 사용하는지 구분하는 것이 비교 포인트입니다.

### 구체적인 벤치마크 후보

- P1. 동일 Windows PC·공급자·모델·언어·계정 티어·프롬프트, Firefox 158/159의 페이지 요약 경로를 비교합니다. 타 브라우저는 동일 공급자 사용이 가능할 때 별도 비교하며 그렇지 않으면 모델 차이를 명시합니다.
- 재현: 정답 사실 12개를 앞·중간·끝에 넣은 공개 합성 장문과 짧은 대조문을 준비 → 페이지 요약 실행 → 실제 전송 프롬프트에 표시되는 URL/본문 범위 기록 → 원문 사실 누락·환각 확인 → URL 접근 불가 합성 페이지에서 실패 고지 확인. 각 문서 5회, 실행 순서 교차.
- 지표: 끝부분 사실 회수율, 잘못된 사실 수, 실패를 정직하게 알리는 비율, 응답 시간, 사용자가 전달 대상을 이해하는지.
- 완료 기준: 12개 사실 체크표와 5회 결과, 공급자/모델/버전 및 전송 범위 증거를 확보합니다. 관찰할 수 없는 네트워크 내부 구현을 추정하지 않습니다. 실제 회사 문서·로그인 토큰·개인 URL은 절대 사용하지 않습니다.
- 미확인: 공급자별 URL 수집 방식, 접근 제한 페이지 처리, 다른 요약 경로의 변경 여부. 모델 정확도 개선은 아직 실측하지 않았습니다. 공급자별 지역·계정·사용 한도도 별도 확인 대상입니다.

## 3 탐색 진입 기본값: 탭 검색 단축키와 비밀번호 사이드바

### 확인된 변화와 근거

[159 Release 노트](https://www.firefox.com/en-US/firefox/159.0/releasenotes/)는 Windows/Linux 탭 검색을 Ctrl+Shift+A로 제공하며, 확장 기능·테마는 Ctrl+Shift+F로 바꾼다고 명시합니다. about:keyboard에서 변경할 수 있습니다. 저장 비밀번호 도구는 따로 추가하지 않아도 사이드바에 기본 제공됩니다. 비밀번호 저장·자동완성 자체의 첫 출시가 아닙니다.

### 사용자 영향과 제품 비교 질문

탭을 많이 여는 사용자의 빠른 찾기 경로가 생기는 대신 익숙한 확장 관리 단축키가 다른 동작을 할 수 있습니다. 비밀번호 관리의 발견 가능성은 높아질 수 있지만 화면 노출·인증 동작까지 변경됐다고 추정하지 않습니다. 삼성 브라우저와는 같은 과제의 진입 단계·학습 부담·키보드 접근성으로 비교합니다.

### 구체적인 벤치마크 후보

- P2. 같은 Windows PC·창 크기·언어·키보드, 공개 탭 30개와 합성 시험 로그인 항목 10개를 사용합니다. Firefox 158/159, 현행 Chrome·Edge·지원 확인된 삼성을 비교합니다.
- 재현 A: 탭 30개를 같은 순서로 열기 → 제목 일부로 지정 탭 5개 찾기 → 이전 확장 관리 단축키를 알고 있는 조건과 처음 배우는 조건을 분리 → 확장 화면 진입 후 돌아오기.
- 재현 B: 기본 사이드바 상태에서 지정한 합성 로그인 항목을 찾기 → 표시/닫기 경로와 인증 요구 관찰 → 키보드만으로 반복. 비밀 값 복사·외부 전송은 수행하지 않습니다.
- 지표: 탭 찾기 시간·오선택·확장 화면 오진입, 비밀번호 관리 진입 조작 수, 포커스 순서·이름 없는 버튼, 닫은 뒤 예상치 못한 내용 잔류.
- 완료 기준: 두 과제를 각 5회 완료해 정확한 키 동작·기본 노출·화면 증거와 실패 사유를 기록합니다. 미노출이나 사용자 지정 단축키는 기본 상태와 혼합하지 않습니다.
- 범위: Windows 우선. macOS의 키 조합은 별도이며 Android에 이 단축키·사이드바 변경을 적용하지 않습니다. 기존 사용자의 커스터마이즈 보존·잠금 정책·지역별 노출은 실기 미확인입니다.
