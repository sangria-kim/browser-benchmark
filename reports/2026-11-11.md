## 유사 상품 탭에 비교를 먼저 제안하는 Edge

- Event ID: `edge-contextual-product-comparison-rollout-20261109`
- Windows·macOS / 정확 버전·채널 미공개 / P2 · conditional.
- 2026-11-09 발표. 관찰일 2026-11-11 KST. 개별 활성화일은 미확인.

### 변경 전후와 사용자 영향
기존에는 사용자가 Copilot에 여러 탭 비교를 요청했다. 이번에는 유사 상품을 보는 상황에서 비교를 먼저 제안하고, 선택한 후 페이지 전체를 읽어 결과를 제시한다. 다중 탭 비교 자체의 최초 도입은 아니다. PM 검토 대상은 반복 탭 전환을 줄이는 진입 방식과 읽기 동의 경계다.

### 삼성 브라우저 비교 질문과 벤치마크
삼성 브라우저에서는 여러 상품을 비교할 때 비교 대상 선택, 페이지 읽기 동의, 원문 확인, 제안 끄기를 어떻게 제공하는가? 공개 근거가 없는 지원 차이는 단정하지 않는다.

같은 상품 세 개를 별도 탭으로 열고 비교 제안, 선택, 후속 질문, 끄기 흐름을 관찰한다. 동일 Windows·계정·지역·언어·사이트 조건에서 수동 비교와 대조한다. 비교 완료 시간, 탭 전환 수, 가격·사양 오류, 제안 방해 빈도를 측정하고 원문으로 답을 확인한다. 각 과제를 3회 반복하고 노출 조건·동의 시점·오류를 설명할 수 있으면 완료다. 실제 시험은 미실행이다.

### 한국 적용과 제한
Copilot 지원 시장을 대상으로 하며 사이트별 차이가 있다. 한국어 쇼핑 안내는 존재하지만 해당 기능의 한국 활성화일·한국어 지원은 확인되지 않았다. 정확 빌드·계정·구독 세부 조건도 별도 확인이 필요하다.
