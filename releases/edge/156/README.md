# Edge 156

[공식 문서](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-relnote-stable-channel)의 156 절을 수집했습니다. 수록 사실과 신규 출시를 구분합니다. Mobile 문서는 업무·학교 계정 중심입니다. 기존 권한·자동완성·자격 증명 항목의 신규성 정정 판단은 유지합니다. IndexedDB SQLite 항목은 이 Stable 본문에서 확인되지 않아 이번 색인에 새 사실로 추가하지 않았습니다.

- eMudhra 인증서 사고 대응 안내
- Windows OneAuth 전환 예고
- Copilot URL allow list 안내
- XSLT 단계적 폐기 예고
- tracing 수집 방식 변경
- 사이트 권한 UI 재기재: 신규성 보류
- 문서 자동완성 재기재: 신규성 보류
- 자격 증명 상세 기능 재기재: 신규성 보류
- 관리 기기의 시작 실행 opt-in
- PDF 정책 폐기
- 관리 업데이트 후 실행 오류 수정
- RemixAvailability 정책
- AutofillAddressEnabled 폐기
- AutofillCreditCardEnabled 폐기
