# Edge 156-mobile

[공식 문서](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-relnote-mobile-stable-channel)의 156 절을 수집했습니다. 수록 사실과 신규 출시를 구분합니다. Mobile 문서는 업무·학교 계정 중심입니다. 기존 권한·자동완성·자격 증명 항목의 신규성 정정 판단은 유지합니다. IndexedDB SQLite 항목은 이 Stable 본문에서 확인되지 않아 이번 색인에 새 사실로 추가하지 않았습니다.

- 일반 버그·성능 수정
- OneAuth SDK 11.2.2
- iOS 업무 계정 전환 수정
- iOS 첫 실행 로그인 개선
- iOS App Proxy 진단 로그
- iOS 계정·로그인 screen reader 개선
- Android 조직 정책 로그인 오류 안내
- Copilot Chat 및 contextual UX 개선
